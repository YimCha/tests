# 模拟考试工具更新说明（10-16）

各位同事，这次更新的重点是把答题操作改得更顺手：不用再把鼠标挪到右下角去点「下一题」了。重新下载最新的 HTML 文件替换旧文件即可生效（错题记录仍保存在各自文件里，规则不变）。

## 一、键盘直接答题（新）

进入考试或刷题后，手不用离开键盘：

- **A–H**（或数字 1–8）：直接选对应选项，判断题用 A=对、B=错也行；
- **← / →**：上一题 / 下一题；
- **Enter**：多选题确认答案；普通题跳下一题；最后一题按 Enter 直接交卷；
- **M**：标记 / 取消标记当前题（仅考试模式）。

页面顶部有快捷键小提示，忘了随时看。用鼠标答题照旧，两种方式随便混用。

## 二、屏幕两侧新增翻题箭头

题目卡左右两侧各有一个「‹ ›」圆形按钮，垂直居中，答完题鼠标不用移到页面底部；到第一题/最后一题时对应箭头会变灰。窄屏幕（手机）上箭头会缩小贴边，不挡选项。

## 三、选完自动跳下一题（可开关）

顶部新增「自动下一题」开关，选择会记住：

- **模拟考试：默认开启**。单选/判断题选中后约半秒自动跳下一题（多选题不受影响，仍需自己确认完再翻页）；
- **刷题练习：默认关闭**（答完要停留看解析）。打开后**答对的题**会自动跳下一题，**答错的题仍然停留**，方便看解析和正确答案。

不想自动跳就把开关关掉，一切照旧。

## 四、主题切换更省事

「跟随系统 / 浅色 / 深色」的切换按钮从首页搬到了**每个页面右上角**的圆形小图标，考试中途也能随时切换。点开后是三个选项直接选一个，不用再连点好几下循环。

## 五、手机端答题按钮吸底

手机上答长题干时，底部的「上一题/下一题/交卷」会固定在屏幕底部，不用滚到底部再找按钮。
