# 模拟考试工具更新说明（10-12）

各位同事，根据大家试用后的反馈，这次更新了三处，另有一处顺手优化。重新下载最新的 HTML 文件替换旧文件即可生效（错题记录仍保存在各自文件里，替换文件后记录需要用「恢复自动保存」找回，和以前一样）。

## 一、新增浅色模式

工具右上角新增了「主题」按钮，点一下在三种状态之间切换：

- **跟随系统**（默认）：电脑/浏览器设的是深色就是深色，浅色就是浅色；
- **浅色**：米白纸感配色，打印或白天投影时更舒服；
- **深色**：原来的样式。

选择会记住，下次打开不用再调。

## 二、错题本能看到完整题目内容了

之前错题本展开只显示答案字母（比如 "ABD"），不知道每个选项说了什么。现在展开后可以看到：

- 完整的题干和**所有选项的正文**；
- 正确答案标绿；
- 你当时**选错的选项标红打叉**；
- 解析照旧。

一点说明：本次更新**之前**积累的错题，因为当时没有记录你选了什么，所以只标绿色的正确答案、不显示红叉；之后再答错的题就都有了。

## 三、模拟考试答错的题，现在也会进错题本

以前只有「刷题练习」里答错才记错题本，模拟考试答错不算。现在交卷后，答错的题自动记入对应岗位的错题本，和刷题的规则一致：

- 错一次记一次，多次答错会累计成「高频/顽固」，方便用「强化练习」重点攻；
- 想消掉记录还是在刷题练习里连对 3 次，自动移入「已掌握」。

## 四、考试时间到自动交卷更顺了

之前时间到了会弹窗问「确定交卷吗？」，点取消考试就卡住了。现在时间一到直接收卷出成绩，不会再卡住。
